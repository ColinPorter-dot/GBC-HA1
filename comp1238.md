## Week 1 - History
- Base-60 (Sexagesimal) used by the Babylonians: twelve segments on one hand (excluding the thumb), with the other hand's fingers being used to track the number of 12s reached, with a max count of 60
- "Typesetting: The process of arranging type to create a page of text. Modern typesetting software (like Adobe InDesign) continues this tradition."
## Week 2 - Bits and Bytes
- Volatile memory cannot retain data when the power is turned off: Non-Volatile memory can retain data for long periods without power
- In any base-_n_ notation, every order of significance (or steps to the _left_ of the decimal point) is equal to the digit multiplied by _n_ raised to the order of significance, i.e. 5 x (16 ^ 2) or 4 x (8 ^ 1)
## Week 3 - Text Structure
- JSON (JavaScript Object Notation), YAML (Yet Another Markup Language), XML (eXtensible Markup Language), HTML (HyperText Markup Language), Markdown
- HTML was proposed by **Tim Berners-Lee**
## Week 4 - Keyboards and Editors
- In UTF-8, the first 128 code points need one byte, which encompasses A-Z & a-z along with 0-9 and some punctuation symbols. Thus, **any single alphanumeric character can be represented with one byte.**
- Word processors are specialized for writing human-consumed text, Text editors are specialized for writing computer-consumed text
## Week 5 - Command Line Interfaces
- Secure Shell (SSH) Protocol is used for connecting with remote machines, and usually looks like `ssh username@server_address` in the CLI
- `cd` changes the working directory. `ls -a` lists all files in a directory. `cat` concatenates a file to the terminal (it just prints its contents, ignore this guy).
